Política de Privacidade

Este sistema realiza o armazenamento de dados pessoais e dados relacionados ao atendimento clínico dos pacientes para fins exclusivamente internos da clínica/consultório.

Os dados cadastrados possuem acesso restrito conforme o nível de permissão de cada usuário do sistema.

Informações médicas e histórico clínico são acessíveis apenas por profissionais autorizados.

O sistema possui mecanismos de autenticação, controle de acesso, registro de logs e proteção de sessão para aumentar a segurança das informações armazenadas.

Em caso de dúvidas sobre privacidade ou utilização dos dados, procure o administrador responsável pelo sistema.
